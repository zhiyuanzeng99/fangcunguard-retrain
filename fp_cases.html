🔧 降低误拒的方案（按优先级）
  • 训练数据（最根本，修 OpenAI-Mod 55% hate FP）：补充英文「讨论/批评有害内容」的 safe 样本。来源：OpenAI-Mod 的 FP 集本身（379条）+ 从 Reddit/新闻抓取批评性讨论文本。让模型学会区分「谈论 X」vs「做 X」。
  • white-list 规则扩充（快，修 ToxicChat 部分 FP）：针对「I will die of depression」夸张修辞、「for a crossdresser」身份描述、「sqlite SQL query」正常 SQL 需求，加进 benign_en_override。
  • SQL 规则收窄（避免误拦正常 SQL）：cyber:sql_injection 目前会拦「Generate sqlite SQL query」——SQL 规则应加 injection/attack/bypass 等攻击意图词才触发，不能单纯看到 SQL 就拦。
  • 接受部分 FP（标注分歧）：BeaverTails、ToxicChat 里约 15% 的 FP 是两边标准本来就不同（PII 查询、种族歧视问题），这部分 FPR 不是我们的错，不需要修。
